# 🎓 Student Information Management System (Java OOP + Swing)

A simple yet aesthetic **Student Information Management System** built in **Java** using **Object-Oriented Programming (OOP)** principles and a **Swing GUI**.  
This project demonstrates **Encapsulation, Inheritance, Polymorphism, and Abstraction** while providing a clean interface to manage student records.

---

## ✨ Features
- ➕ Add new students with ID, Name, Age, and Course.
- ❌ Remove students from the system.
- 📋 Display all students in a modern table view.
- 🔍 Search and find students by ID.
- 🎨 Aesthetic GUI with modern fonts, emojis, and dialogs.

---

## 🛠️ Technologies Used
- **Java (JDK 8+)**
- **Swing (GUI toolkit)**
- **OOP Concepts**: Encapsulation, Inheritance, Polymorphism, Abstraction
